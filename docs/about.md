# About

## Project Name
Budget Guard

## Short Description
Budget Guard helps you stay on budget. It uses AI to watch your spending on your Bunq card.

## Why We Built It
We built Budget Guard to help people control their money. Many people spend more than they plan. This tool gives clear rules and helps you save.

## What Problem It Solves
People often lose track of their spending. Budget Guard sets spending limits and stops you when you reach them. It also lets you ask the AI for a one-time unblock if you need to buy something important.

## Tech Stack
- **Next.js** for the web app  
- **AWS** amplify and rout53 for hosting
- **Node.js** for the backend
- **TypeScript** for type safety
- **React** for the frontend
- **Drizzle ORM** for database  
- **PostgreSQL** as the database  
- **Bunq API** for banking integration  
- **Neon** for the database
- **NvidiaCHAT** llama-3.1-70b-instruct for AI processing
- **OpenAI** GPT for natural-language processing  
- **Tailwind CSS** for styling
